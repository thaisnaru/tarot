# /referencias/figma/

Exporte os frames do seu arquivo Figma como PNG/JPG e coloque aqui. Diferente de uma referência de estilo (tipo o Brilliant era), este material é a **spec visual literal** do app — cores, espaçamento, tipografia e layout devem seguir de perto o que está desenhado aqui.

Sugestão de nomes (um arquivo por tela, mesmo nome das telas da spec):

```
01-home.png
02-trilha.png
03-licao.png
04-fim-de-licao.png
05-mesa.png
06-enciclopedia.png
07-perfil.png
```

Se exportar variações (ex.: estado de erro, painel de feedback aberto), acrescente um sufixo: `03-licao-feedback.png`.

Não existe conexão automática com o Figma neste ambiente — a atualização é manual: você exporta de novo sempre que o design mudar.
